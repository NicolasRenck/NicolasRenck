## Projetos em Destaque

### [Grax.ia](https://github.com/NicolasRenck/Grax.ia)
> Sistema de registro de serviços e faturamento via WhatsApp com IA. O usuário manda uma mensagem de texto ou áudio contando o que fez, e a IA (Groq/Llama + Whisper) extrai e estrutura os dados automaticamente — cliente, descrição, valores. Gera relatório mensal em PDF sob demanda, entregue direto no WhatsApp.
